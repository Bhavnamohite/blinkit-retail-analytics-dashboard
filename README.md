# Blinkit Retail Analytics: Revenue Insights & Store Performance Dashboard

## 📊 Project Overview
An interactive and executive-ready retail analytics dashboard built in **Microsoft Excel** using official Blinkit corporate brand identity. This platform analyzes **₹1,201,681** in gross revenue across 8,523 total items sold to uncover key performance indicators (KPIs), structural growth trends, and optimization pathways for fulfillment outlets.

## 📈 Key Insights & Business Value
* **Revenue Anchor:** Grocery Stores and Supermarket Type 1 formats generate the absolute highest baseline of outlet contributions.
* **Geographic Demographics:** Outlets zoned in Tier 2 and Tier 3 cities maintain a highly stable, uniform performance profile across High, Medium, and Small store scales.
* **Product-Market Fit:** "Fruits and Vegetables" along with "Household Essentials" dominate customer item selection, representing the core volume drivers.

---

## 🛠️ Technical Stack & Features Used
* **Data Sources:** Structured relational retail store matrices.
* **Core Mechanisms:** Dynamic PivotTables, calculated fields, and multi-slicer relational report connections.
* **UI/UX Design:** Custom shape container cards, custom color matching gradients, asset positioning, and chronological timeline formatting.

---

## 📂 How to Open the Project
1. Download the `Blinkit Retail Performance & Revenue Insights Dashboard.xlsx` file from this repository.
2. Open the file in Microsoft Excel (2016 or newer).
3. Ensure macros/connections are enabled if prompted, and use the dynamic slicers on the left and bottom right to filter the data interactively.
